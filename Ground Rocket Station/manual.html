1. System Architecture & Capabilities

Rocket Ground Station (RGS) provides mission-critical telemetry capture, live aerodynamic visualization, and post-flight recovery guidance for high-power rocket flights. Communicating via USB serial radio receivers, RGS decodes packed binary telemetry at 20 Hz with zero dropped frames, monitors pyrotechnic deployment circuits, and logs every data point with per-sample flush persistence.

Telemetry & Data Link
  • 20 Hz Binary Stream with XOR-0xAA verification
  • Automatic corrupted frame rejection
  • Text debug line passthrough to Event Log
  • Per-sample flushed CSV black-box logging
Recovery & Analysis
  • Dual-mode GPS: Satellite Map & Tactical Radar
  • Concentric metric range rings (50m to 5km)
  • Airborne wind drift & landing prediction
  • One-click GPS copy with Google Maps links

2. Telemetry Packet Protocol Specification

The telemetry link transmits 28-byte binary frames in standard Little-Endian IEEE-754 format:

Offset Field Type Units Description
0..1 Sync Header uint8[2] 0xAA 0x55 Frame synchronization word
2..5 Timestamp uint32 ms Flight computer uptime since boot (t_ms)
6 Flight State uint8 Enum 0=Pad, 1=Boost, 2=Coast, 3=Drogue, 4=Main, 5=Landed
7..10 Acceleration float32 m/s² Vertical gravity-compensated acceleration
11..14 Altitude float32 m AGL Barometric altitude above launch pad ground level
15..18 Latitude float32 Deg WGS84 GPS Latitude in decimal degrees
19..22 Longitude float32 Deg WGS84 GPS Longitude in decimal degrees
23 Satellites uint8 Count Tracked GPS satellite constellation count (>=4 for 3D fix)
24 Continuity uint8 Bitmask Bit 0: Drogue pyro continuity; Bit 1: Main pyro continuity
25 Checksum uint8 XOR Running XOR of payload bytes 2..24 with seed 0xAA

5. Pre-Flight Checklist & Field Safety Procedures

Phase Checklist Item Verification & Acceptance Criteria
Pre-1 Radio Hardware Connect USB receiver. Select COM port in RGS and click Connect.
Pre-2 Data Rate Confirm RATE: ~20 Hz on bottom status bar and green packet counter.
Pre-3 GPS Acquisition Verify Sats >= 4 and coordinate jitter stabilizes under 5 meters.
Pre-4 Pad Latch Click Latch Pad. Verify blue pad square appears and Downrange reads 0.0 m.
Pre-5 Barometric Test Under Safety tab, check confirmation box and click TEST BARO. Altimeter responds.
Pre-6 Pyro Continuity Verify Drogue and Main cards both indicate green OK.
Pre-7 Launch Readiness Gate Verify GATE card indicates bright green GO FOR LAUNCH.
Pre-8 Arm & Launch Arm launch controller. Voice announcer calls "Liftoff detected" at motor ignition.

7. Avionics Firmware Integration (C++ / Arduino)

#include <Arduino.h>

struct __attribute__((packed)) TelemetryPacket {
    uint8_t  sync1;        // 0xAA
    uint8_t  sync2;        // 0x55
    uint32_t timestamp_ms; // Flight computer uptime
    uint8_t  flight_state; // 0=Pad, 1=Boost, 2=Coast, 3=Drogue, 4=Main, 5=Landed
    float    accel_z;      // Vertical acceleration (m/s^2)
    float    altitude_m;   // Barometric altitude AGL (m)
    float    latitude;     // GPS decimal degrees
    float    longitude;    // GPS decimal degrees
    uint8_t  satellites;   // Tracked GPS satellite count
    uint8_t  continuity;   // Bit 0 = Drogue, Bit 1 = Main
    uint8_t  checksum;     // Running XOR checksum
};

void sendTelemetry(uint8_t state, float az, float alt, float lat, float lon, uint8_t sats, bool drogueOk, bool mainOk) {
    TelemetryPacket pkt;
    pkt.sync1 = 0xAA;
    pkt.sync2 = 0x55;
    pkt.timestamp_ms = millis();
    pkt.flight_state = state;
    pkt.accel_z = az;
    pkt.altitude_m = alt;
    pkt.latitude = lat;
    pkt.longitude = lon;
    pkt.satellites = sats;
    pkt.continuity = (drogueOk ? 0x01 : 0x00) | (mainOk ? 0x02 : 0x00);

    uint8_t* ptr = (uint8_t*)&pkt;
    uint8_t cs = 0xAA;
    for (int i = 2; i < 25; i++) {
        cs ^= ptr[i];
    }
    pkt.checksum = cs;

    Serial1.write((uint8_t*)&pkt, sizeof(pkt));
}
